# hr-attrition-dashboard
An interactive Excel dashboard using the IBM HR Analytics dataset aimed to help HR spot where and why employees leave.

## Data source

[IBM HR Analytics Employee Attrition & Performance](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset) by pavansubhash on Kaggle. It's a fictional dataset created by IBM data scientists, shared under the [Open Database License (ODbL) v1.0](https://opendatacommons.org/licenses/odbl/1-0/). Individual values are under the [Database Contents License (DbCL) v1.0](https://opendatacommons.org/licenses/dbcl/1-0/).
